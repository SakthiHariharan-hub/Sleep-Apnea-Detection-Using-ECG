# Sleep Apnea Detection Using ECG Signals

## 📌 Overview

This project detects Sleep Apnea using ECG (Electrocardiogram) signals using Machine Learning and Deep Learning techniques. The system preprocesses ECG signals, extracts features, and predicts whether a patient has sleep apnea.

---

## 🚀 Features

- ECG Signal Preprocessing
- Signal Segmentation
- Feature Extraction
- Random Forest Classifier
- Convolutional Neural Network (CNN)
- Performance Evaluation
- Binary Classification (Apnea / Normal)
